    THE CITY IS QUIET.
    
        
    PALE deploys a field unit on your machine. It reads, writes and runs things inside one sealed folder, and it asks you before it touches anything.
    
        
    This setup takes a minute: an API key, a folder for the unit to work in, and a few preferences.
    
      
    
      
    
        
    ESTABLISH LINK
    
        
    The unit thinks with Claude through your Anthropic API key. Create one at console.anthropic.com → API keys.
    
        
        
    Stored in your OS keychain (Windows Credential Manager, macOS Keychain), never in the workspace.
          API usage is billed by Anthropic separately from any Claude subscription.
    
        
    A key is already stored. Leave this empty to keep it.
    
      
    
      
    
        
    CHOOSE A SECTOR
    
        
    The sector is the folder the unit lives in. Its sandbox/ subfolder is the only place it can touch. Its bunker/ keeps memory, logs and sessions.
    
        
    
        
    Put files you want help with into sandbox/, or point PALE at an existing project folder later in Settings.
